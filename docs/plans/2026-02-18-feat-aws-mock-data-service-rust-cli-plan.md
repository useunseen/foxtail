# feat: Add AWS-compatible Mock Data Service in Rust

## Overview
This plan implements a high-performance Rust-based service (`aws-mock`) that acts as a "fidelity bridge" for LocalStack. It solves the issue where LocalStack cannot query Cost Explorer data and replaces fragmented Python mock scripts with a unified, protocol-aware mock server.

## Problem Statement / Motivation
Currently, mock data is generated by multiple slow Python scripts, and the agent has no way to query Cost Explorer APIs against LocalStack (since LocalStack doesn't support the query APIs). This creates a "fidelity gap" between development and production.

## Proposed Solution
A Rust binary providing two distinct workflows:
1.  **`gen`**: Discovers LocalStack resources and populates a SQLite DB with synthetic metrics/costs.
2.  **`serve`**: An Axum server implementing AWS JSON 1.0 (Cost Explorer) and AWS Query/XML (CloudWatch) protocols.

## Technical Approach
- **Protocol Dispatch**: Axum middleware will detect the service (CloudWatch vs. Cost Explorer) via `Host` or `X-Amz-Target` and toggle between XML and JSON serializers.
- **Dynamic Time**: To avoid staleness, SQLite will store time as **offsets** (e.g., `-3600` seconds from "now"). The server will calculate absolute timestamps at request time.
- **Persistence**: `sqlx` with `SQLite` for async-friendly, local-first storage.

## Acceptance Criteria
- [ ] `aws-mock gen` populates SQLite with resources discovered from LocalStack.
- [ ] `awslocal cloudwatch get-metric-statistics` (XML) returns realistic metrics from the service.
- [ ] `boto3.client('ce').get_cost_and_usage()` (JSON) returns realistic costs from the service.
- [ ] Data remains "current" (not stale) even if the server runs for several days.

## MVP

### services/aws-mock-data-service/src/main.rs
```rust
use axum::{Router, routing::post, response::IntoResponse};

#[tokio::main]
async fn main() {
    let app = Router::new().route("/", post(handler));
    let addr = "0.0.0.0:8080".parse().unwrap();
    println!("Starting AWS Mock Service on {}", addr);
    axum::Server::bind(&addr)
        .serve(app.into_make_service()).await.unwrap();
}

async fn handler() -> impl IntoResponse {
    // Protocol dispatch logic (JSON 1.0 vs Query/XML)
    "AWS Mock Service"
}
```
